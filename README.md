# Hi, I'm Gonzalo Plaza Rueda 👋

I'm a Software Engineer based in Málaga, Spain, specialised in frontend
development. This repository is my portfolio — the site where I put together who
I am, what I've worked on, and the things I'm learning along the way.

**Live at [gonzaloplazarueda.com](https://gonzaloplazarueda.com)**

## What you'll find there

- **A bit about me** — where I come from and what I care about as an engineer.
- **My experience** — the companies I've worked with and what I did at each one.
- **Personal projects** — things I've built on my own time, mostly to learn
  something new or to solve a problem I actually had.
- **A blog** — notes on frontend, architecture and web performance. Things I
  figure out while building, written down so they don't get lost.

The whole site is bilingual: everything is available in both Spanish and
English.

## A little more about me

My professional career as a developer started in 2021, but my relationship with
technology goes back a lot further. Since 2016 I'd been repairing devices — both
software and hardware — and helping people choose the right one for them. That's
where the habit of taking things apart to understand them comes from, and I've
never really lost it.

Since then I've worked on ecommerce projects and web applications, always with
the same focus: interfaces that are fast, accessible and hold up as they grow.

I'm a native Spanish speaker and I get by in English at a B1 level.

## Built with

Next.js, React and TypeScript, with Sass for the styles and MDX for the blog
posts. Everything is statically generated and there are four colour themes to
pick from.

If you're curious about how it's put together, the first post on the blog walks
through the technical side of it in detail, using this very repository as the
example.

## Running it locally

```bash
pnpm install
pnpm dev
```

Then open [localhost:3000](http://localhost:3000).
